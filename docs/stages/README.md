# Архив этапов разработки (`docs/stages/`)

> [!NOTE]
> **Назначение папки:** Хранение несгораемых сжатых итогов закрытых этапов (спринтов / вех разработки) проекта (например, `stage_01_core_prototype.md`, `stage_02_combat_alpha.md`).

---

## Регламент использования

1. **Создание отчёта:**  
   Формируется агентом при закрытии очередного этапа по шаблону [`stage_template.md`](stage_template.md).
2. **Именование:**  
   Строгий формат: `stage_XX_<краткое_имя_этапа>.md` (где `XX` — номер этапа: `01`, `02`, `03`...).
3. **Несгораемая история:**  
   В отличие от временных точечных логов в `docs/tasks/`, файлы из `docs/stages/` **никогда не удаляются**. Они служат вечным журналом развития проекта, фиксируя, что именно было достигнуто на каждом шаге.
4. **Связка с главным хабом:**  
   Ссылка на каждый закрытый этап фиксируется в [`docs/start_work.md`](../start_work.md) в секции «Навигатор по этапам».
