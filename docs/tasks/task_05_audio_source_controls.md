## 2. Как это реализовано
В Gradio 6.31.0 кнопки выбора источника имеют размер 22×22 px. Пользовательский `padding: 4px 10px` оставлял SVG лишь 2 px по ширине, поэтому вместо иконок отображались точки.

Кнопки получили фиксированный размер 36×36 px и `flex: 0 0 36px`, отступы 8 px, SVG — размер 20×20 px без сжатия. Высота панели теперь определяется содержимым. Потомки кнопок наследуют цвет выбранного состояния; это правило специфичнее общего цвета аудиопанели. Штатные обработчики, подписи доступности и SVG сохранены.

## 3. Зачем это было сделано так
Локальный CSS устраняет конфликт со штатными размерами Gradio, сохраняя загрузку файлов и запись с микрофона. Правила перекраски графика ограничены его обёрткой, чтобы не менять геометрию других SVG.
