## 1. Что было сделано
- Полный визуальный редизайн интерфейса [`app.py`](../../app.py) по референсу пользователя (стилистика Apple Glassmorphism / Neumorphic Clean UI):
  * Светлый органический градиентный фон с мягким размытием;
  * Матовые полупрозрачные карточки (`glass-panel`) с `backdrop-filter: blur(28px)` и нежными градиентными бордерами;
  * Глубокая контрастная угольно-черная карточка (`dark-panel`) с параметрами файла и паспортом команды (Орынбек Гумаров, Арсен Успанов, Сәрсенғалиева А.М., Digital Qazaqstan Day 2026);
  * Черные кнопки-пилюли `pill-btn` (`↗ Запустить анализ`) со стрелкой и тенями.
- Добавлены новые акустические и аналитические метрики в ядро [`voiceguard/detector.py`](../../voiceguard/detector.py):
  * **SVG Sparkline (волна риска):** векторная кривая Безье под главным процентом риска, отображающая динамику уверенности модели по всем окнам;
  * **Достоверность детекции (`confidence_pct`):** автоматический расчет надежности входного аудио;
  * **Голосовая активность речи (`speech_ratio_pct`):** доля активных реплик против пауз;
  * **Динамика интонаций (`dynamics_pct`):** вариативность спектрального центроида $F_0$;
  * Оригинальные метаданные файла (частота дискретизации в кГц, длительность).
- Создан 1-клик лаунчер [`VoiceGuard.bat`](../../VoiceGuard.bat) для мгновенного запуска приложения и открытия браузера.
- Сервер успешно перезапущен и доступен по адресу `http://127.0.0.1:7860`.
