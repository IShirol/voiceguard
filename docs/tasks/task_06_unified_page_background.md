## 2. Как это реализовано
Раньше одинаковый непрозрачный фон рисовался на каждом из пяти вложенных уровней. Размеры и начала координат градиентов различались, поэтому границы контейнеров были заметны.

Теперь фон принадлежит только `body`. `min-height: 100vh` покрывает пустую часть экрана, не ограничивая рост страницы и прокрутку. `background-attachment: fixed` привязывает градиенты к окну, чтобы их положение не менялось при изменении высоты содержимого. Внешние контейнеры сохраняют прозрачность в обеих темах. Из общего правила убрана анимация `background`, которая могла временно создавать отдельные подложки; анимация цвета текста и оформление карточек сохранены.

Фон задан отдельными свойствами `background-color`, `background-image`, `background-attachment`, `background-repeat`. При браузерной проверке обнаружено, что сочетание сокращённого `background` с переменными и отдельного `background-attachment` в одном правиле приводило к пустым значениям при сериализации стилей Gradio; явные свойства устраняют этот конфликт.

## 3. Зачем это было сделано так
Единственный слой фона даёт непрерывные градиенты без границ между прямоугольными контейнерами. Достаточно CSS: переключатель продолжает менять существующие переменные палитры через класс `body.vg-dark`.
