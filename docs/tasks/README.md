# Директория точечных логов (`docs/tasks/`)

> [!NOTE]
> **Назначение папки:** Хранение подробных технических отчётов по отдельным закрытым задачам текущего этапа (например, `task_01_player_movement.md`, `task_02_combat_system.md`).

---

## Регламент использования

1. **Создание лога:**  
   По завершении задачи агент (или субагент `docs-archivist` / `engine-coder`) создаёт файл по шаблону [`task_template.md`](task_template.md).
2. **Именование:**  
   Строгий формат: `task_XX_<краткое_имя_на_латинице>.md` (где `XX` — двухзначный номер задачи: `01`, `02`, `03`...).
3. **Связка с сессией:**  
   Ссылка на созданный файл обязательно указывается в [`docs/session.md`](../session.md) рядом с пунктом чек-листа.
4. **Временный характер («Сборка мусора»):**  
   Файлы в этой папке **живут только до окончания текущего этапа**.  
   При завершении этапа:
   - Ценные архитектурные решения, формулы и гайды переносятся в `docs/knowledge_base/`;
   - Сжатый итог уходит в `docs/stages/`;
   - **Все файлы `task_XX_*.md` удаляются**, освобождая место под задачи следующего этапа и сохраняя проект чистым.
