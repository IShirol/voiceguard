## 1. Что было сделано
- Протестирован реальный голос пользователя из Telegram (`samples/real_orych_telegram.ogg` / `.wav`): детектор показал **7.9% вероятности ИИ** (уверенно распознан живой человек).
- Протестирован реалистичный сэмпл сгенерированного голоса ElevenLabs с эмоциональными тегами аварии (`samples/fake_elevenlabs_kuchka.mp3`). Модель зафиксировала пиковый риск до **59.9%** на участках связной речи.
- В ядро [`voiceguard/detector.py`](../../voiceguard/detector.py) добавлено вычисление `max_ai_probability_pct`, границы `start_sec`/`end_sec` и флаг `is_suspicious` для каждого 5-секундного окна.
- В интерфейс [`app.py`](../../app.py) внедрены:
  * Отображение двух ключевых метрик: **Средняя вероятность ИИ** и **Пиковый риск в сегменте**.
  * Адаптивный статус-баннер: при пике $\ge 50\%$ выводится предупреждение об обнаружении подозрительных синтезированных фрагментов.
  * Цветовая подсветка строк таблицы сегментов (красный акцент + бейдж `⚠️ Подозрительно` для фрагментов с риском $\ge 50\%$).
- Сервер перезапущен и проверен на `http://127.0.0.1:7860`.
