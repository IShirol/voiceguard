# Вечная база знаний проекта (`docs/knowledge_base/`)

> [!NOTE]
> **Назначение папки:** Хранилище «дистиллированных» и несгораемых знаний проекта: архитектурных гайдов, спецификаций систем, описаний механик, правил интеграции сторонних API и решений типичных проблем.

---

## Регламент использования

1. **Как сюда попадают статьи:**  
   - При завершении каждого этапа агент просматривает точечные отчёты из `docs/tasks/`.
   - Любое полезное решение, формулы, гайды по код-стайлу или архитектуре выносятся сюда отдельными статьями по шаблону [`article_template.md`](article_template.md).
2. **Как агент читает базу знаний:**  
   - Агент **НЕ читает все статьи подряд** на старте сессии, чтобы не перегружать контекст.
   - В [`docs/start_work.md`](../start_work.md) создаётся рубрикатор (карта ссылок). Агент обращается к конкретной статье только тогда, когда задача касается этой подсистемы.
3. **Обновление статей:**  
   Если архитектура подсистемы изменилась в ходе рефакторинга, статья в `knowledge_base/` актуализируется, сохраняя актуальную истину о проекте.
